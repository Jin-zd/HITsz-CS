# 基于记忆增强的细粒度仇恨言论识别框架

## 1. 整体架构

本框架提出了一种基于记忆增强的智能代理（Memory-Augmented Agent），旨在解决细粒度中文仇恨言论识别任务。该框架的核心思想是模拟人类学习过程，通过不断从错误中反思和总结经验，来提升模型在复杂任务上的表现。

整体架构主要包含两个核心模块：**经验池（Experience Pool）** 和 **推理与反思模块（Inference and Reflection Module）**。

在训练阶段，代理接收一个输入文本，首先从经验池中检索相关的历史经验。这些经验与输入文本一同被整合进一个精心设计的提示（Prompt）中，并提交给一个大型语言模型（LLM）以生成初步的识别结果。随后，系统将模型输出与真实标签进行比对。若存在差异，反思模块将被激活，生成对该错误的分析和总结，形成一条新的“经验”，并将其存入经验池中。

在推理阶段，代理同样会为新的输入文本检索相关经验，并利用这些经验来指导LLM生成最终的、更准确的识别结果。通过这种方式，代理能够动态地利用累积的知识，有效应对多样化和具有挑战性的仇恨言论。

## 2. 经验池设计

经验池是本框架的长期记忆中枢，负责存储、管理和检索从历史任务中学习到的经验。

-   **经验的定义与生成**：经验并非原始数据，而是对模型在特定案例上犯错原因的深刻反思和总结。当模型在训练中产生错误输出时，反思模块会通过一个专门的LLM提示，引导模型分析错误根源（如对评论对象、论点或目标群体的误判），并提炼出具有指导意义的、简洁的经验教训。

-   **经验的表示与索引**：为了实现高效的经验检索，我们采用语义相似度匹配。每条经验都与引发该反思的原始输入文本相关联。我们使用先进的文本表示模型（如BGE-M3）将原始输入文本编码为高维向量。这些向量被存储在一个专门为高效相似性搜索设计的FAISS索引库中。这种设计使得系统能够根据新输入文本的语义内容，快速定位到最相关的历史经验。

-   **检索机制**：当处理新的输入时，系统首先将其编码为向量，然后在FAISS索引中进行查询，以找到语义上最接近的历史案例。检索过程基于向量间的L2距离计算相似度，返回最相关的Top-K条经验。这种基于内容的检索方式确保了所提取的经验与当前任务高度相关，为模型提供了精准的决策支持。

## 3. 推理与反思设计

推理与反思模块是代理的核心认知引擎，负责执行任务、从错误中学习，并将学习成果转化为可复用的经验。

-   **推理流程**：无论是训练还是评估，推理流程都始于经验检索。系统从经验池中获取与当前输入最相关的经验。这些经验被格式化后，动态地嵌入到发送给核心LLM的提示中。提示不仅包含了任务描述和输入文本，还明确指示模型要“利用之前的经验进行输出的生成”。这种“检索-增强-生成”（Retrieval-Augmented Generation, RAG）的模式，使得LLM的决策不再是零样本或少样本的，而是基于一个不断扩充的知识库，从而显著提高了识别的准确性和鲁棒性。

-   **反思与学习机制**：反思是实现框架自我完善的关键。在训练过程中，当模型的预测结果与标准答案不符时，系统会触发反思流程。该流程将模型的错误输出和正确答案一同呈现给一个扮演“反思专家”角色的LLM。该LLM的任务是深入剖析错误原因，并总结出一条具有普适性的、可操作的经验。这条新生成的经验随后被向量化并存入经验池，完成了从“犯错”到“学习”再到“记忆”的闭环。通过这个持续学习的循环，框架的能力随着处理数据的增多而不断进化。
